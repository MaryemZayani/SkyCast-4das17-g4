# SkyCast V4

Angular 21 — mise à jour de la V3.

```powershell
npm install
npm start
```

Accueil `/`, utilisateur `/user/dashboard`, administrateur `/admin/dashboard`.

Les dossiers métier et routes V3 sont conservés. Données fictives, CRUD local, carte schématique et courbes illustratives. Aucun accès sécurisé ni connexion backend. La recherche de la barre supérieure filtre les rubriques du menu.

Compilation à vérifier avec `npm run build`.
